## The folder

The test of necessity: a page is necessary when someone running, trusting, extending or translating the site needs it and no other page says it. The likely shape: `kernel.md` and `editing.md` are the design, kept; `tlo.md` the format, kept; `kit.md` is seventeen lines and may fold into `kernel.md` or the README; `exports.md`, `network.md` and `dependencies.md` are generated and stay (their scripts own them); `translation.md`, `threat-model.md`, `crypto/*`, `self-host.md` are kept; `github-setup.md` is one person's checklist and may go to history or to `self-host.md`; `transparency.md`'s dated notes are history and its live checks belong beside the threat model. - **Every kept page is current.** Each sentence that names a path, a command, a flag, a count, a language, an app, a budget, a setting's words or a menu's order is checked against the code and the running site at this commit and brought to the truth: twenty-one languages, ten apps, the drawer with no app rows and the mark as its way home, the share dialog's Edit link and Present link, the sheet's words-then-numbers columns, the Calendar's bar, the address written when typing stops for two seconds, the first paint, the map's tiles, the foot's words and version. ## The skill

- **Shipped.** `skill/tinyoffice/` (SKILL.md and whatever it needs) is in the npm package's `files` (`packages/doc/package.json`), so `npx tinylittleoffice` carries it; the package's README says so.
- **Installed in one line.** The CLI gains `skill`: `npx tinylittleoffice skill` prints SKILL.md to stdout; `npx tinylittleoffice skill --into <dir>` writes it to `<dir>/tinyoffice/SKILL.md` (the layout Claude Code reads from a project's `.claude/skills/` and a person's `~/.claude/skills/`), creating the folder and refusing to overwrite a file it did not write unless `--force`. The CLI's `--help` lists it beside `shapes`, `example` and `try`.
- **Named where an agent or a person looks.** The repository README's agents line says the three ways in order: `/llms.txt` for a fetch, `npx tinylittleoffice` for a runtime, and the skill for Claude Code with the install line. `/llms.txt`'s runtime line names the skill in a clause (the file stays under 6 KB: `test/llms.test.ts` holds it; trim elsewhere if a clause does not fit, and say what). `llms-full.txt` (the template) has a short section "The skill" saying what it is and the install line. The package README has the same.
- **One source.** The skill's text stays generated from `SKILL.tpl.md` by `npm run skill`; the CLI reads the shipped file; nothing is copied by hand.
