# History

These are the record of how the tree was built, and are not maintained: they describe the tree as it was when
each was written, and name things that have since changed or gone. The current documents are listed in
[docs/README.md](../README.md).

- [rebuild.md](rebuild.md): the plan of the rebuild, its phases, and the rules kept while building.
- [gap-analysis.md](gap-analysis.md): what the old tree did, feature by feature, and where the rebuilt tree stood.
- [translation-plan.md](translation-plan.md): the first plan for the languages, before they were built.
- [transparency.md](transparency.md): the pre-launch plan for making the promises checkable by a stranger, item by
  item with the date each was built; moved here 2026-10-12, its checks now in docs/threat-model.md.
- [github-setup.md](github-setup.md): the checklist of the repository's settings, set by hand on GitHub when it was
  opened; moved here 2026-10-12, the settings a deploy assumes now in docs/self-host.md.
- [directives/](directives/README.md): the brief given for each piece of work, round by round.
- [reviews/](reviews/2026-10-11.md): the reviews of the tree, and what each found.

The tree before the rebuild keeps its whole history in the repository, tagged `v0-before-rebuild`.
